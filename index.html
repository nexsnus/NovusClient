Installation

So installierst du ihn

Dauert ne Minute.

Herunterladen

Klick oben auf „Für Windows herunterladen“. Die Datei heißt NovusClient-Setup.exe und kommt direkt von GitHub.

Öffnen

Doppelklick auf die Datei. Windows zeigt bei neuen Programmen manchmal einen blauen Hinweis:

Dann auf „Weitere Informationen“ und danach auf „Trotzdem ausführen“ klicken. Warum das kommt, steht unten bei „Sicherheit“.

Installieren & einloggen

Durchklicken, Launcher starten, mit Microsoft anmelden. Fertig.
